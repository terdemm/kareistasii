# Kullanım

Yalnızca Kare-Ustasi-v7.zip dosyasını skill olarak yükleyip etkinleştirin. Ayrı model veya ses dosyası yüklemeniz gerekmez. Türkçe videoda ilk kullanımda gerekli çalışma paketi PyPI üzerinden, Supertonic 3 modeli resmî GitHub sürümünden otomatik indirilir; sonraki ses üretimi yereldir. GitHub ve release-assets.githubusercontent.com erişimi gerekir. İngilizce Kokoro dosyaları ve çalışma yolu korunmuştur. Konuyu, dili ve istediğiniz tarzı doğal bir cümleyle belirtmeniz yeterlidir.
